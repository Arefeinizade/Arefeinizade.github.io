Teaching

Advanced Machine Learning

Institut Polytechnique de Paris (IP paris) · Jan - Mar 2026

This lecture explores advanced Machine Learning techniques, covering neural networks, ensemble learning, probabilistic models, and optimization methods. Students will gain insights into model selection, dimensionality reduction, explainable AI, and Natural Language Processing (NLP). The lecture combines theoretical foundations with practical Python-based implementations to address complex real-world problems.

Level

M2

Master 2 Biomedical Engineering (BME) track

Prerequisites

Fundamentals of ML + Python Programming

A solid understanding of basic machine learning algorithms, linear algebra, probability, and statistics, along with proficiency in Python programming and familiarity with NumPy, Pandas, and Scikit-learn.

Format

3 sessions (tutorials + lab)

Course outcomes

Learning objectives

By the end of this lecture, students will be able to:

01

Understand and implement advanced Machine Learning models, including neural networks, ensemble learning methods, and probabilistic models.

02

Apply optimization, regularization, and hyperparameter tuning techniques to improve model performance and generalization.

03

Explore dimensionality reduction, feature selection, and explainable AI techniques to interpret and analyze complex datasets and model predictions.

04

Develop and evaluate advanced Machine Learning workflows using Python, with applications in real-world data analysis and Natural Language Processing (NLP).
