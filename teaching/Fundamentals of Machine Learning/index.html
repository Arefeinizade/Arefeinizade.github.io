Teaching

Fundamentals of Machine Learning

Institut Polytechnique de Paris (IP paris) · Sep - Nov 2026

This lecture introduces the fundamental concepts and techniques of Machine Learning, covering essential topics such as supervised and unsupervised learning, regression, classification, and model evaluation. Students will explore key algorithms, including linear regression, decision trees, logistic regression, K-Nearest Neighbors (KNN), and clustering methods, while gaining practical experience with Python-based implementations and real-world applications.

Level

M1

Master 1 Biomedical Engineering (BME) track

Prerequisites

Basic ML + Python programming

Linear algebra, probability, and comfortable Python usage.

Format

4 sessions (tutorials + lab)

Concepts, small derivations, practical examples, and guided notebook-style exercises.

Course outcomes

Learning objectives

By the end of this lecture, students will be able to:

01

Understand the fundamental concepts of Machine Learning, including supervised and unsupervised learning, and identify their practical applications.

02

Apply essential data preprocessing techniques and use Python libraries to prepare, analyze, and visualize datasets.

03

Understand and implement fundamental regression and classification algorithms, including linear regression, logistic regression, decision trees, K-Nearest Neighbors (KNN), and Linear Discriminant Analysis (LDA).

04

Explore unsupervised learning techniques, including K-means, hierarchical clustering, and DBSCAN, to discover patterns and structures in data.

05

Evaluate and compare Machine Learning models using appropriate performance metrics, cross-validation techniques, and bias-variance analysis.

06

Develop practical Machine Learning workflows, from data preparation and model training to performance evaluation and interpretation of results.
